1Two parts: a passive mark, an active glyph

The body below is a real contenteditable: click anywhere, including inside marked words, and the caret goes there. The marked words carry only a passive underline and faint tint in the kind colour; they are not buttons. The trigger is a glyph in the left padding of the block, a real <button>: a dot when words differ, a bar for lines or blocks (the removal bar carries its count), a wedge where content exists only in site. Marks are ProseMirror decorations, so they move with the text while I type. Taking theirs is one transaction on the range, so ⌘Z undoes it and the caret stays.

Setup

Clone the template and point the serve config at your tailnet domain. The script below pulls the Dockerfile, compose file and serve config and rewrites localhost to your MagicDNS name.

sh# Get template filesTAILNET=$(tailscale status --json | jq -r '.MagicDNSSuffix')TEMPLATE="https://raw.githubusercontent.com/mrgnw/svelte-docker-tailscale/main"curl -O "$TEMPLATE/Dockerfile" & \curl -O "$TEMPLATE/compose.yml" & \curl -O "$TEMPLATE/serve.json" & wait# Set up Tailscale configecho "\n/tailscale" >> .gitignore+1 line

2. Create serve.json

Create a reusable, tagged auth key in the Tailscale admin console.

Only two variables are required:

shTS_AUTHKEY=TS_PORT=4177 # this needs to be unique for each container
+1 ¶ · 19 words

If you did the above in your terminal, you can add them to your .env with this:

shecho "TS_AUTHKEY=$TS_AUTHKEY" >> .envecho "TS_PORT=$TS_PORT" >> .env
