## Setup

Clone the template and point the serve config at your tailnet domain. The script below pulls the Dockerfile, compose file and serve config and rewrites localhost to your MagicDNS name.

```sh# Get template filesTAILNET=$(tailscale status --json | jq -r '.MagicDNSSuffix')TEMPLATE="https://raw.githubusercontent.com/mrgnw/svelte-docker-tailscale/main"curl -O "$TEMPLATE/Dockerfile" & \curl -O "$TEMPLATE/compose.yml" & \curl -O "$TEMPLATE/tailscale_serve.json" & wait# Set up Tailscale configecho "\n/tailscale" >> .gitignoreecho "\ntailscale_serve.json" >> .gitignore```

Tailscale needs `network_mode: service:tailscale` on the app container so the sidecar owns the network namespace.

Get an auth key from the [Tailscale admin console](https://login.tailscale.com/admin/settings/keys)

Only two variables are required:

```shTS_AUTHKEY=TS_PORT=4177 # this needs to be unique for each container```

`TS_PORT` has to be unique per container — two sidecars on the same port fight over the tailnet node name.
